# Hospedagem Caminho das Praias

Site institucional da **Hospedagem Caminho das Praias**, na Rua Magé, 12, Pé Pequeno, Niterói/RJ.

## Tecnologias

- HTML5 + CSS3 + JavaScript puro
- Sem frameworks ou dependências externas (exceto Google Fonts)
- Hospedagem: GitHub Pages

## Estrutura

```
├── index.html
├── RESEARCH.md          # Pesquisa e dados confirmados
├── ASSETS-SOURCES.md    # Fontes de imagens e assets
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── favicon.svg
```

## Nota

Tipos de acomodação, comodidades, valores e fotos devem ser confirmados com o anfitrião antes da publicação oficial. Nenhum valor é informado no site.
